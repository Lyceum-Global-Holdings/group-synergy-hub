# One-Page PDF: Functions & Integrations Report

Generate a single-page A3 landscape PDF summarizing every module, integration, and platform capability of the Lyceum Global Holdings ERP, delivered to `/mnt/documents/`.

## Content Sections

**1. Header**

- Title: "Lyceum Global Holdings — Group Synergy Hub"
- Subtitle: "Functions & Integrations Overview"
- Generated date, brand color band (#1F4E78)

**2. Core Modules** (compact 3-column grid, 11 modules / 68 sub-modules from `moduleConfig.ts`)

- Warehouse, Procurement, Sourcing, Finance, Construction, Production, TUH (Customer), Management, Admin, Social Media, Auth

**3. Integrations & Services** (icon/bullet grid)

- Telegram Bot (site reports, scheduled reports, test connection)
- Email (Resend — approval notifications, password reset, admin user invites)
- MFA / 2FA (TOTP setup, recovery codes, MFA challenge)
- Supabase (Postgres + RLS, Auth, Storage, Edge Functions, Realtime)
- AI Analysis (Lovable AI Gateway — floor plan analysis, KPI insights)
- 3D Modeling (floor-plan analyzer / construction visualization)
- QR Codes (bulk PDF/PNG label printing for assets)
- PDF / Excel / CSV report rendering (jsPDF, xlsx, autoTable)
- SAP-compatible entity mappings

**4. Platform Capabilities** (compact list)

- RBAC with company-scoped RLS, hierarchical location permissions
- Multi-tenant company isolation
- Approval workflows (centralized console)
- Stock reconciliation & FIFO batch tracking
- Three-way match (PR/PO/GRN/Invoice)
- Bulk import (CSV with auto-code allocation)
- Virtualized tables, keyset pagination
- Realtime sync bus
- Scheduled jobs (pg_cron + pg_net)
- Audit logs, error management, performance dashboard

**5. Quality & Engineering**

- Vitest unit testing (MFA, ProtectedRoute, etc.)
- Test environment / test suite runner page
- Web Vitals budget, perf telemetry overlay
- ESLint, TypeScript strict, security scanner integration

**6. Footer**

- Confidential — Internal Use · Generated by Lyceum ERP

## Technical Approach

- Python script using `reportlab` Platypus, single A3 landscape page
- Multi-column flowables with compact 8pt body / 10pt headers
- Brand palette: primary `#1F4E78`, accent `#2E75B6`, table header fill
- Source data: read `src/constants/moduleConfig.ts`, `supabase/functions/`, `src/lib/reports/`, `src/pages/auth/`, `src/utils/bulkQRCode*.ts`, `package.json` for dependencies
- QA: convert PDF → JPEG via `pdftoppm`, inspect for overflow/clipping, iterate until clean (single page, no overflow)
- Output: `/mnt/documents/LGH_Functions_and_Integrations.pdf`
- Deliver via `<lov-artifact>` tag
